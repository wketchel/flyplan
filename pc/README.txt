FlyPlan for PC  (version @VERSION@)

SETUP
1. Unzip this folder somewhere permanent, such as Documents\FlyPlan PC.
   Don't move it later: the app keeps its data with the folder's location.
2. Double-click "FlyPlan.cmd". It opens the planner in its own
   Microsoft Edge window. (Opening index.html in Edge or Chrome works too.)
   Tip: right-click the .cmd file > Send to > Desktop (create shortcut).

SYNC WITH THE TABLET (Google Drive)
- Install Google Drive for desktop if you haven't. Your Drive shows up as G:.
- First device: tap Sync > Create sync file, and save it in Google Drive
  (on the PC: G:\My Drive).
- Other device: Sync > Use existing file, and choose that same file.
- Markers, boundaries and saved missions sync. Map files, offline areas and
  settings don't.
- When Edge asks to let the site edit the file, choose "Allow on every visit"
  so you aren't asked again.

YOUR ORTHOMOSAIC (MBTiles)
- Map menu > My maps > Import MBTiles, and pick your .mbtiles file. The PC reads
  it where it is, so leave it there (your Google Drive folder works fine).

SENDING TO THE DRONE
- Plan on the PC and save it in Missions. Sync brings it to the tablet, and you
  send it to the controller from the tablet.
- Or use Save KMZ and copy the file to the controller yourself.

Needs Microsoft Edge or Google Chrome. Firefox can't open map files or the sync
file.
